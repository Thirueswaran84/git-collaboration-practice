
# Git Collaboration Practice

## Project Overview
A hands-on internship project to learn Git, GitHub, and enterprise development workflows.

## Objectives
- Understand Git fundamentals.
- Practice repository management.
- Learn branching strategies.
- Understand commits and merge conflicts.
- Practice Pull Requests.
- Learn code review workflows.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- PowerShell

## Learning Activities
1. Git installation and configuration.
2. Repository cloning.
3. Branch creation.
4. Semantic commits.
5. Merge conflict resolution.
6. Pull Requests.
7. Code reviews.
